|----------|-------------|
| Host secrets/ → container /run/secrets | Operator-controlled files cross into process memory |
| resolve-env → loadConfig | Merged env must not leak secrets in error strings |
| Git index | secrets/ and data/ must never be tracked |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-01 | Information Disclosure | Secret files in git | mitigate | .gitignore secrets/ data/; verify with git check-ignore |
| T-05-02 | Information Disclosure | Zod validation errors | mitigate | Reuse SECRET_ENV_KEYS redaction via loadConfig; test no echo |
| T-05-03 | Tampering | Malicious secret file content | mitigate | trim only; loadConfig min length; operator controls host files |
| T-05-04 | Elevation | Overwriting env with file when env set | mitigate | env wins over file in resolvePilotEnv (tests) |
| T-05-SC | Tampering | npm install in spike container | accept | Spike uses lockfile only; no new packages in app |
