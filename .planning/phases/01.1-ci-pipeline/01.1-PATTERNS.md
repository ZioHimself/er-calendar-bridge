```1:20:tsconfig.json
  },

  "exclude": ["node_modules", "dist", "test"]
}
```

**Core pattern** (`01.1-RESEARCH.md` Pattern 2 — verified locally):

```json
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "rootDir": ".",
    "noEmit": true
  },
  "include": ["test/**/*.ts"],
  "exclude": ["node_modules", "dist"]
}
```

**Why `rootDir: "."` override:** Base sets `rootDir: "src"`. Test files import `../../src/...` (see `test/helpers/parse-ics.ts` lines 1–5). Without override, `tsc -p tsconfig.test.json` fails TS6059.

**Test import convention to preserve** (lines 1–5):

```1:5:test/helpers/parse-ics.ts
import {
  parseIcsToSourceEvent,
  getCategories,
} from '../../src/adapters/ical/index.js';
import type { SourceEvent } from '../../src/domain/types/index.js';
```

**Constraint:** Same strict options as `src/` — no relaxed compiler rules (D-06). Do not change base `tsconfig.json` include/exclude for build emit.

## Shared Patterns

### npm script surface (CI contract)

**Source:** `package.json` lines 9–15
**Apply to:** All four CI jobs and README local checklist

CI must invoke existing script names only — no inline `vitest`, `eslint`, or `tsc` commands in workflow YAML. Keeps local and CI paths identical.

### Strict TypeScript dual-config

**Source:** `tsconfig.json` + new `tsconfig.test.json`
**Apply to:** `typecheck` script, typecheck CI job

- `tsconfig.json`: `src/` only, emits to `dist/` via `npm run build`
- `tsconfig.test.json`: `test/**/*.ts` only, `noEmit: true`
- Both inherit `strict: true`, `noUncheckedIndexedAccess: true`

### ESM + Node 24

**Source:** `package.json` + `tsconfig.json`
**Apply to:** CI setup-node, local dev docs

```json
{ "type": "module", "engines": { "node": "24.x" } }
```

Module resolution: `"NodeNext"`. Test imports use `.js` extensions when referencing `src/`.

### eslint-only quality gate (no Prettier)

**Source:** `eslint.config.mjs`, Phase 1 D-12
**Apply to:** lint CI job; do not add format job

Flat config with `recommended` preset only — type safety in tests is `tsc`'s job, not eslint `strictTypeChecked`.

### Fixture-only tests (no CI secrets)

**Source:** `test/smoke.test.ts`, `test/helpers/load-fixture.ts`
**Apply to:** test CI job (TEST-05)

Tests load local `.ics` fixtures via `readFile` — no env vars, no provider credentials:

```16:25:test/helpers/load-fixture.ts
export async function loadFixture(
  tier: 'public' | 'internal' | 'sensitive' | 'untagged' | 'recurrence',
  name: string,
): Promise<{ ics: string; expected: FixtureExpected }> {
  const dir = join(FIXTURES_ROOT, tier);
  const ics = await readFile(join(dir, `${name}.ics`), 'utf8');
  const expected = JSON.parse(
    await readFile(join(dir, `${name}.expected.json`), 'utf8'),
  ) as FixtureExpected;
  return { ics, expected };
}
```
